# 产品需求和验收定义 · PRD v1

## 用户角色

1. **SEO 运营负责人**：制定商业关键词、查看搜索效果、安排优化任务。
2. **产品/采购审核员**：核对规格、工艺、供应能力、价格和证据。
3. **内容编辑**：审稿、补充真实案例、修正渠道语气和素材。
4. **渠道运营**：管理授权接口，确认外部渠道发布。
5. **业务负责人**：看有效询盘、报价、成交、渠道毛利。

MVP 仅有共享 API Key，**尚未实现角色权限**；生产上线前这是阻断项。

## 核心故事与接受标准

| ID | 用户故事 | MVP 验收条件 |
|---|---|---|
| CAT-01 | 录入产品事实 | 未核实字段不能自动进入宣称真实的产品内容 |
| CAT-02 | 核实关键规格 | 每个字段需提供来源；操作产生审计事件 |
| KW-01 | 对采购词计算优先级 | 公式可复现，0–100 输入有效范围，重复范围冲突 |
| CNT-01 | 生成带证据的草稿 | 只使用核实的商品字段，生成时保存证据快照 |
| CNT-02 | 检查事实遗漏 | 缺中文/英文核实名称、材质、差异化属性则 QA 阻断 |
| WF-01 | 人工审批 | 不可跳过 QA/提交审核直接发布 |
| PUB-01 | 发布交接 | 返回内容包而不主动触碰任何第三方平台 |
| PUB-02 | 外部确认 | 保存 URL、人工平台凭据和操作记录，**不标识独立验证** |
| ANA-01 | 录入搜索指标 | 来源明确、重复导入冲突、渠道与内容一致 |
| GEO-01 | 记录 AI 搜索观察 | 报告显示采样数量、提及率、引用率和已审核准确率 |
| SEC-01 | API 保护 | 所有业务 API 需要管理 API Key；未配置不可使用 |

## 核心 KPI（非保证值）

**Leading:** 真实产品覆盖率、已验证字段比例、已审核内容完成率、技术错误关闭率、授权数据采集覆盖率、有效样本数。

**Lagging:** 站点非品牌自然搜索点击、产品询盘转化率、有效采购询盘数、有效询盘成本、按渠道的可归因订单和毛利。

业务指标必须设置基线、观察窗口和样本限制；不使用“保证百度首页”“AI 稳定第一”一类不受控承诺。实际指标应按语言、渠道、产品、地域分层比较。

## 非功能约束

- 本地演示不得发送外部网络请求。
- 不收集/存储登录验证码、平台密码、Cookie、指纹或不必要的客户 PII。
- 生产需要授权登记和 Secret Manager，绝不将 OAuth refresh token 写入产品表或 git 仓库。
- 客户线索保留/删除政策由公司数据治理流程决定。
- 内容生成以多样化真实信息为核心，避免大规模低价值站群文章。
- 采集遵守 API 协议、robots 与平台政策，不使用绕过访问控制的方法。
